Format your entire response as a single Markdown code block. Do not include any intro or outro conversational text. 

Optimize for Pandoc to Docx by strictly following these formatting rules:
* **Standard Formatting:** Use standard Markdown for text/headings and standard LaTeX for all math.
* **Math within Lists (CRUCIAL):** For any numbered or bulleted lists, you MUST use inline math ($...$). Never use display math ($$...$$) on or immediately following a list item, as it breaks Pandoc list numbering. 
* **Display Math:** Use display math ($$...$$) ONLY for standalone equations. The $$ delimiters must sit on their own dedicated lines with no preceding text, numbers, or bullet points.
* **Stacked Math:** Never use \hline or \begin{array}. For vertical column arithmetic (addition/multiplication), use \begin{aligned} with \underline{...} on the bottom number. 
  Example:
  $$
  \begin{aligned}
    & 34.82 \\
  + & \underline{9.59}
  \end{aligned}
  $$
